# Task 2: External Data Collection (Social Signals)

## 1. Project Overview

This task focuses on collecting publicly accessible social signals related to **Jasper**, an AI writing tool. The collected data will help analyze public discussions, engagement, sentiment, and trends related to the product.

## 2. Selected Product

- **Product:** Jasper
- **Genre:** AI Writing Tools
- **Project:** Product Launch Success Predictor Using Social Signals

## 3. Planned Data Sources

The following platforms will be considered for collecting publicly accessible data:

- **Reddit:** User discussions, comments, and opinions about Jasper.
- **YouTube:** Public video discussions and available engagement metrics.
- **LinkedIn:** Public posts and professional discussions about Jasper.
- **Product Hunt:** Product-related discussions and available user feedback.
- **X (Twitter):** Public posts and discussions, where accessible.

Actual sources used will be documented after data collection.

## 4. Data Collection Method

Data will be collected from publicly accessible posts and discussions using methods permitted by each platform. Depending on availability, collection may involve manual recording or approved APIs.

Only data that can be accessed and verified will be recorded. Unavailable metrics will be left blank rather than estimated or invented.

## 5. Planned Dataset Schema

| Column | Description |
|---|---|
| post_id | Unique identifier for the collected record |
| platform | Platform where the post was found |
| timestamp | Post publication date and time, when available |
| username | Public username, if necessary and available |
| raw_text | Relevant post text |
| likes | Number of likes, when available |
| comments | Number of comments, when available |
| shares | Number of shares, when available |
| url | Link to the original post |

## 6. Social Signals to Analyze

The project will investigate:

- Post volume and discussion frequency
- Engagement through likes, comments, and shares
- Positive, negative, or neutral sentiment
- Trending keywords and recurring topics
- Influencer mentions, where identifiable
- Discussion velocity over time, where timestamps are available

## 7. Data Quality and Limitations

The dataset will be checked for duplicate records, missing values, inconsistent formats, and irrelevant posts. Platform restrictions, unavailable historical data, and differences in engagement metrics may limit comparisons.

The actual number of records, collection dates, sources, and collection methods will be added after the data has been collected and verified.
